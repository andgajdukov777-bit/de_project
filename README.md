Учебный проект для Демонстрационного экзамена (ДЭ).

Стек технологий:
* **Backend:** Python (Flask)
* **Database:** PostgreSQL (библиотека psycopg2)
* **Frontend:** HTML, Jinja2

Реализованный функционал:
* Регистрация и авторизация пользователей (с валидацией полей).
* Личный кабинет пользователя (создание заявок, просмотр статусов, отзывы).


* Панель администратора (доступ по логину: `Conf2027`, пароль: `Demo77`).
* Управление статусами заявок (Новая, Мероприятие назначено, Завершено).

Как запустить:
1. Установить зависимости: `pip install flask psycopg2-binary`
2. Создать БД `conference_db` в PostgreSQL и выполнить SQL-скрипт из корня проекта.
3. Запустить сервер: `py app.py`

4. Перейти в браузере по адресу: `http://127.0.0.1:5000/login`
